# AI Fact of the Day

AI Fact of the Day is a small website that shares an interesting fact. When a
visitor opens the page, AWS Lambda asks Amazon Bedrock to write a fact about a
random topic, then returns a complete webpage to the visitor.

The name says “of the day,” but this version makes a new fact **each time the
page is opened or refreshed**. It does not run on a daily schedule or save
older facts.

## What it does

- Chooses a topic such as space, animals, history, or mathematics.
- Uses Amazon Bedrock Nova Lite to generate a short fact about that topic.
- Shows the fact in a responsive webpage.
- Lets visitors copy the fact or ask for another one.
- Shows a helpful error page if the fact cannot be generated.
- Logs generation errors in AWS, without showing technical error details to
  website visitors.

The text is generated by AI and may be wrong. The page reminds visitors to
check a trusted source, especially before relying on important information.

## How it works

1. A visitor opens the AWS Lambda Function URL.
2. Lambda chooses a topic and asks Amazon Bedrock for a fact.
3. Lambda puts the fact into the webpage and sends the page back.
4. The visitor can copy the fact or reload the page to request another.

This project uses AWS Lambda for the website and Amazon Bedrock for the AI
response. It does not use a separate web server, database, or frontend build
tool.

## Run the tests on your computer

Use the existing Python environment on your computer; you do not need to
create another one. In this workspace, the existing environment is in the
parent `github` folder. Open PowerShell in the `ai-fact-of-the-day` folder and
run:

```powershell
& "..\.venv\Scripts\python.exe" -m pip install -r requirements.txt
& "..\.venv\Scripts\python.exe" -m unittest discover -s tests -t . -v
```

These tests do not call AWS or spend AWS credits. The dependency installation
uses the existing environment.

## Put it on AWS

You need an AWS account, permission to create Lambda functions and IAM roles,
and access to the Amazon Nova Lite model in Amazon Bedrock. This example uses
the `us-west-2` region.

### 1. Enable the Bedrock model

In the AWS Console, select **US West (Oregon) / us-west-2**, open
**Amazon Bedrock**, and make sure Amazon Nova Lite is available to your
account in that region.

### 2. Create a Lambda execution role

Create an IAM role for **Lambda** and give it permission to write logs to
CloudWatch. Add a policy that lets this function call the Nova Lite model:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "bedrock:InvokeModel",
      "Resource": "arn:aws:bedrock:us-west-2::foundation-model/amazon.nova-lite-v1:0"
    }
  ]
}
```

Use the role ARN when you create the function.

### 3. Make a zip file

In PowerShell, from the project folder, run:

```powershell
Compress-Archive -Path lambda_function.py -DestinationPath function.zip -Force
```

The AWS Lambda Python runtime already includes boto3, so this single-file
function does not need its Python packages added to the deployment zip.

### 4. Create the Lambda function

In the AWS Console, create a Lambda function with these settings:

- **Function name:** `ai-fact-of-the-day`
- **Runtime:** Python 3.12
- **Execution role:** the role created above
- **Timeout:** 15 seconds or more

In the function's **Code** section, upload `function.zip` and choose
**Deploy**. The handler name should be `lambda_function.handler`. By default
the code uses model ID `amazon.nova-lite-v1:0`; if you want another model,
set the `MODEL_ID` Lambda environment variable to that model's ID.

### 5. Create a webpage URL

In the Lambda function settings, choose **Function URL**, create a URL, and
select **NONE** authentication to make the page publicly accessible. Open the
URL in a browser to see a fact.

**Important:** anyone who has the public URL can request facts. Each request
runs Lambda and calls Bedrock, which can incur AWS charges. Keep an eye on
your AWS billing and remove or restrict the public URL when you no longer need
it.

## Update the deployed page

After changing `lambda_function.py`, make a fresh `function.zip` with the
PowerShell command above, upload it to the Lambda function, and choose
**Deploy**.
